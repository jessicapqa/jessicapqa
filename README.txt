# 🚀 Code Journey

### A journey through Quality Assurance and Test Automation

**Learn. Build. Test. Evolve.**

## 📌 Sobre o projeto

O **Code Journey** é um laboratório de aprendizado e desenvolvimento voltado à área de Quality Assurance (QA), com foco na construção de estruturas de automação de testes para diferentes plataformas: Web, Mobile e API.

A proposta é explorar diferentes linguagens de programação, frameworks, bibliotecas e ferramentas, desenvolvendo projetos independentes e aplicando boas práticas de automação, organização de código, arquitetura e qualidade de software.

O repositório busca proporcionar experiência prática com diferentes tecnologias, permitindo comparar abordagens, desenvolver frameworks reutilizáveis e aprofundar conhecimentos em automação de testes.

## 🎯 Objetivos

- Desenvolver estruturas de automação para aplicações Web, Mobile e APIs.
- Explorar diferentes linguagens de programação e frameworks.
- Aplicar padrões de projeto e boas práticas de desenvolvimento.
- Construir arquiteturas organizadas, reutilizáveis e escaláveis.
- Implementar cenários de testes funcionais e de regressão.
- Explorar ferramentas de gerenciamento, versionamento e integração contínua.
- Ampliar conhecimentos em engenharia de qualidade e automação de testes.

## 🌐 Web Automation

Desenvolvimento de estruturas de automação para aplicações web, explorando diferentes frameworks e linguagens de programação.

**Tecnologias:**

| Framework | Linguagem |
|---|---|
| Playwright | Python |
| Selenium | Python |
| Cypress | TypeScript |
| Robot Framework | Python |

**Aplicações utilizadas para os testes:**

- [SauceDemo](https://www.saucedemo.com/) – Aplicação de e-commerce para testes de autenticação, produtos, carrinho e checkout.
- [DemoQA](https://demoqa.com/) – Aplicação para exploração de componentes web, formulários, elementos e interações.

**Cenários explorados:**
- Login e autenticação.
- Navegação e interação com elementos.
- Pesquisa e seleção de produtos.
- Carrinho de compras.
- Processo de checkout.
- Validações de formulários.
- Testes funcionais e de regressão.

## 📱 Mobile Automation

Desenvolvimento de estruturas de automação para aplicações mobile, explorando diferentes abordagens de automação, integração com dispositivos e execução de testes.

**Tecnologias:**

| Framework / Ferramenta | Linguagem |
|---|---|
| Robot Framework + Appium | Python |
| Appium | Java |
| JUnit | Java |

**Cenários explorados:**
- Automação de aplicações Android.
- Interação com elementos nativos.
- Navegação entre telas.
- Validação de componentes e funcionalidades.
- Testes funcionais e de regressão.
- Execução automatizada em dispositivos e emuladores.

## 🔌 API Automation

Desenvolvimento de estruturas de automação para testes de APIs, explorando diferentes ferramentas e linguagens para validação de serviços e integrações.

**Tecnologias:**

| Framework | Linguagem |
|---|---|
| Robot Framework | Python |
| Playwright | TypeScript |
| Cypress | JavaScript |
| REST Assured | Java |

**Cenários explorados:**
- Requisições HTTP (GET, POST, PUT, PATCH e DELETE).

Validação de status codes.

Validação de headers e payloads.

Testes positivos e negativos.

Validação de contratos e respostas.

Testes de integração.

Tratamento de dados e autenticação.

📈 Evolução do projeto

O Code Journey é um projeto em constante evolução, no qual novas tecnologias, ferramentas e abordagens serão incorporadas ao longo do desenvolvimento.

Cada projeto representa uma oportunidade de experimentar diferentes soluções, comparar frameworks, aprimorar habilidades de programação e construir estruturas de automação cada vez mais robustas.

Mais do que automatizar testes, a proposta é compreender diferentes abordagens de engenharia de qualidade e desenvolver uma visão ampla sobre automação de software.
